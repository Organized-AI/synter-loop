# Synter ad operations

1. Start with read-only status, performance, reconciliation, and tracking-health evidence.
2. Label platform, GA4, CAPI/sGTM, and CRM figures separately and attach a run ID.
3. Propose spend changes only; apply paths remain disabled in this local build.
4. Unknown effects, broken tracking, exceeded caps, freeze state, unattended execution, and missing evidence are hard stops. Jev never authorizes.
5. Never send prompts, tool results, credentials, or personal data to GA4/sGTM.
6. A human decides release or promotion.
