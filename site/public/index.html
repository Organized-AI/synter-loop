A closed loop for agent ad spend.

synter-loop is a Hermes Agent plugin for Synter's cross-platform ad tools. Before your agent changes a budget it checks the caps, the tracking and the numbers, then asks you. Afterwards it grades the change, and the grade teaches the next decision.

hermes plugins install Organized-AI/synter-loop

Needs Hermes 0.23.0 or later and a Synter API key. Writes are dry runs until you approve them.

The loop

  1. Spend Guard decides. Every Synter write passes caps, a dry run, the tracking gate and Jev's score, then waits for your approval. Unattended runs only propose.
  2. Tag Witness checks tracking in a real browser: dataLayer pushes and the tags that actually fired.
  3. Truth Layer checks the numbers. Platform claims sit next to GA4, CAPI and CRM, and wrong figures get a footnote.
  4. Agent ROAS grades each approved change once enough days have passed.
  5. Jev learns from the grades through jev-gateway, so the next score is better informed. Jev never approves.

Agent runtime capture records every prompt, tool call and token. Agent P&L measures the agent like an ad account.

Demo

The demo video is published with the submission. Until then, watch real runs on the live page.

What it will not do

  • Approve its own changes. A person approves every write; Jev only scores.
  • Spend without a dry run first, or past your caps.
  • Act during unattended runs. Cron and propose-only mode record proposals instead.
  • Send prompts or tool results to analytics. Capture is off by default, and only metadata ever leaves the capture store.
