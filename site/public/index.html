In development · Hermes Agent Plugin Hackathon

A closed loop for agent ad spend.

synter-loop is a Hermes Agent plugin built on Synter. Before your agent changes a budget, it checks the caps, the tracking and the numbers, then asks you. Afterwards it grades the change, and the grade informs the next decision.

Install

hermes plugins install Organized-AI/synter-loop

Needs Hermes 0.23.0 or later and a Synter API key. Writes are dry runs until you approve them.

01 · The loop

Every write goes around the loop.

Five stages sit between your agent and your ad accounts. Each one records what it saw, so every decision can be replayed later.

Agent runtime capture records every prompt, tool call and token. Agent P&L measures the agent like an ad account.

02 · Guarantees

It proposes. You decide.

  1. 01No self-approval

    A person approves every write. Jev only scores.

  2. 02Dry run first

    Nothing spends without a dry-run preview, and nothing goes past your caps.

  3. 03Quiet when unattended

    Cron runs and propose-only mode record proposals instead of acting.

  4. 04Prompts stay put

    Capture is off by default. Only metadata ever leaves the capture store; prompts and tool results never reach analytics.
