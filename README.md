# synter-loop

A Hermes Agent plugin that runs a closed loop on ad spend through Synter: Spend Guard decides, Tag Witness checks tracking, Truth Layer checks the numbers, Agent ROAS grades each change, and Jev learns from the grades.

**Live site:** https://synter-loop.jordan-691.workers.dev/ (what the plugin does, the interactive 3D loop and the demo video).

Work in progress for the Hermes Agent Plugin Hackathon. Build order: [`PROMPT.md`](PROMPT.md). Rules: [`AGENTS.md`](AGENTS.md).
